# Phase 2 file explanation

| File Path                                                                    | Responsibility                      | Important Functions       | Dependencies                  | Connected Files                | Request/Data Flow                             | Important Design Decisions                      |
| ---------------------------------------------------------------------------- | ----------------------------------- | ------------------------- | ----------------------------- | ------------------------------ | --------------------------------------------- | ----------------------------------------------- |
| `apps/api/prisma/schema.prisma`                                              | Defines MySQL and foundation schema | `SystemSetting` model     | Prisma                        | Migration, seed, Prisma client | Prisma maps model operations to MySQL         | Business models are deferred until their phases |
| `apps/api/prisma/migrations/20261030100000_initial_foundation/migration.sql` | Creates foundation table            | SQL DDL                   | MySQL                         | Prisma migration engine        | Migration creates `system_settings`           | Additive, non-destructive migration             |
| `apps/api/prisma/seed.ts`                                                    | Seeds repeatable development data   | `main`                    | Prisma Client                 | Schema                         | Upsert writes initial setting                 | Safe reruns through `upsert`                    |
| `apps/api/src/config/env.ts`                                                 | Validates runtime configuration     | `envSchema`               | dotenv, Zod                   | App, Prisma environment        | Process environment becomes typed config      | Requires explicit MySQL URL                     |
| `apps/api/src/database/prisma.ts`                                            | Owns one Prisma client              | `prisma`                  | `@prisma/client`              | App, server, seed              | Shared pool avoids per-request clients        | Centralized connection lifecycle                |
| `apps/api/src/app.ts`                                                        | Builds Express application          | Health route              | Express, Helmet, CORS, Prisma | Server, middleware             | Request enters middleware and route           | Exported app supports isolated tests            |
| `apps/api/src/server.ts`                                                     | Starts and stops HTTP server        | `shutdown`                | Node, Prisma                  | App                            | Signals close HTTP and DB resources           | Graceful shutdown                               |
| `apps/api/src/common/middleware/request-id.middleware.ts`                    | Correlates requests                 | `requestIdMiddleware`     | Node crypto                   | App, error handler             | Adds response/request ID                      | Supports tracing without logging secrets        |
| `apps/api/src/common/middleware/request-logger.middleware.ts`                | Logs request timing                 | `requestLoggerMiddleware` | Express                       | App                            | Finish event logs status and duration         | Does not log bodies or credentials              |
| `apps/api/src/common/middleware/validate.middleware.ts`                      | Reusable Zod validation             | `validate`                | Zod, Express                  | Future routes                  | Parses body, params, query before controllers | Centralizes validation boundary                 |
| `apps/api/src/common/middleware/not-found.middleware.ts`                     | Handles unknown routes              | `notFoundHandler`         | Express                       | App, AppError                  | Converts unmatched route to 404 error         | Consistent API response                         |
| `apps/api/src/common/errors/app-error.ts`                                    | Represents expected errors          | `AppError`                | JavaScript                    | Not-found and future services  | Carries status/code to handler                | Avoids leaking internal details                 |
| `apps/api/src/common/errors/error-handler.ts`                                | Produces safe error responses       | `errorHandler`            | Prisma, Zod, Express          | App                            | Maps typed errors to JSON                     | Explicit 503 for DB initialization              |
| `apps/api/src/types/express.d.ts`                                            | Types request correlation ID        | Express augmentation      | TypeScript                    | Request middleware and handler | Makes `requestId` type-safe                   | Avoids unsafe casts                             |
| `apps/api/tests/app.test.ts`                                                 | Tests foundation behavior           | Health and 404 tests      | Jest, Supertest               | App, mocked Prisma             | Tests HTTP without developer DB               | Isolated DB mocks                               |
| `apps/api/jest.config.mjs`                                                   | Configures API tests                | Jest configuration        | Jest, ts-jest                 | Test files                     | Transpiles TypeScript ESM tests               | Serial execution prevents shared mock races     |
